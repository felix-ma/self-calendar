怎么订阅 / 导入
  • iPhone：Safari 点上面的「订阅」，或打开 webcal:// 链接
  • Android：Google 日历网页版「其他日历 → 从网址添加」，填本页的 schedule.ics 地址
  • 只要一次性：点「下载 .ics」，用日历打开
  • 订阅会定期刷新，下载不会自动更新
  • 提醒时间按通勤算：5 km 内电动车、更远打车
  • iPhone 注意：订阅/导入的 .ics 只有一个颜色，系统也不会采用事件里的提醒；要按班次分色 + 逐事件提醒，请用 iCloud 共享的「排班·早班 / 晚班 / 白班」三个日历
  • 「下载闹钟快捷指令」得到 paiban-alarm.shortcut：iPhone 上用 Safari 下载后点开即可加入快捷指令 App。它只联网、不需要日历权限；建议设一个每天 00:05 的时间自动化并关掉「运行前询问」
