排班日历

只含今天及以后还没结束的班次

下载 schedule.ics 订阅日历（自动同步）

订阅后 GitHub 更新会自动同步；下载导入是一次性复制。

导入 iPhone

  • 用 Safari 打开本页，点上面的按钮
  • 下载完成后点「日历」图标，选「添加全部」
  • 或在「文件」里点开 .ics，选择「日历」
  • 事件里带社康地址，点地点即可导航

导入 Android

  • 用 Chrome 打开本页，点上面的按钮下载
  • 点通知或「文件」里的 schedule.ics
  • 选择「日历」或「Google 日历」导入

分享给同事

  • 把 schedule.ics 直接发微信 / 邮件
  • 对方点开文件即可导入日历
